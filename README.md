# 🎬 Netflix Clone
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
Учебный pet-project — клон Netflix с каталогом фильмов и сериалов.  
Проект демонстрирует мои навыки во frontend-разработке: работа с API, динамическая отрисовка контента, адаптивная вёрстка и базовая архитектура приложения.

---

## 🚀 Технологии

- HTML5  
- CSS3
- JavaScript 
- REST API  
- Адаптивная вёрстка

---

## ✨ Что есть

- Главная страница с обновляемым списоком фильмов 
- Поиск фильмов по ключевому слову
- Карточки с адаптируемым рейтингом 
- Модальное окно по клику на постер 
- Адаптация под мобильные устройства
- Пагинация


---

## ▶️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/username/netflix-clone.git
   ```
2. Запустить через Live Server
